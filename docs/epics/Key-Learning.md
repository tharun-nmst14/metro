# Key Learning Journey – Metro UFM Demo

## 1. Scala
- Learned Scala fundamentals, classes, traits, collections, and functional programming.
- Applied Scala to implement application logic and reusable components.

## 2. SBT
- Learned dependency management, compilation, and test execution.
- Used SBT to build and run the application.

## 3. Apache Wicket
- Learned component-based web development and HTML-to-Scala component binding.
- Implemented pages, forms, navigation, and AJAX-based UI updates.
- Troubleshot component ID mismatches and AJAX rendering issues.

## 4. Enterprise Application Architecture
- Understood layered architecture: Presentation, Service, Repository, and Database.
- Learned separation of concerns and the Repository Pattern.
- Followed the application flow from user interaction to database retrieval.

## 5. JDBC and Oracle Database
- Learned JDBC connectivity, SQL execution, and result mapping.
- Integrated supplier lookup with Oracle through the repository layer.
- Learned database configuration and connection management.

## 6. Configuration and Security
- Learned to configure applications using environment variables and JVM properties.
- Understood secure credential handling and least-privilege database access.

 

## Conclusion
The Metro UFM Demo project strengthened my understanding of **Scala, Apache Wicket, SBT, JDBC, Oracle Database, and enterprise application architecture**. It provided practical experience in building server-side web applications, integrating database operations, troubleshooting issues, and planning maintainable and testable software.

# metro-ufm-demo

`metro-ufm-demo` is an enterprise-style demonstration project scaffold for a Scala and SBT application using Apache Wicket on Jetty with Oracle Database access through JDBC and PL/SQL where required.

## Technology Stack

- Scala
- SBT
- Apache Wicket
- Jetty
- Oracle Database
- PL/SQL
- JDBC / Oracle JDBC Driver
- HTML
- CSS
- Git
- GitHub Copilot

## Current Scope

- Login
- Common Application Shell: header, METRO branding, navigation, user information, version, date/time, and context bar
- Ordering: DSD Order with filter criteria, supplier selection, and order result
- Ordering: Stock Assignment with filter criteria and stock assignment result
- Parameter: Steering Parameter only

## Out Of Scope

- Parameter: Order Reports, Purchase Area, PAXD Supplier, Sales Lines, DCs, VTO Supplier, Row Selector, Interfaces, Delivery DC Supplier, and DSD Supplier Whitelist
- Other Ordering functions: Store Quantities, Self Service Stock Orders, Supplier Assignment, Stock Order, Stock Order Corr, Order Maintenance, and File Upload

Implementation will be performed epic-by-epic after the scaffold and documentation are accepted.
